# Notification

Une notification push qui tombe : vente, client, message.

## Quand
Une vente, un message, un résultat qui arrive tout seul.

## Règles
- Icône de l'app en accent, nom de l'app et heure en micro, message en gras.
- Les notifications s'empilent vers le bas, une par mot.

## À fournir
L'app, le message, l'heure.

## Briques
Card, Heading, Icon, LogoSlot.

## Origine
Créé pour abdoul.dev en suivant la logique des composants existants.
