# BarChart

Graphique : les barres montent mot après mot.

## Quand
Une progression, un effet « à fond », une croissance.

## Règles
- Fenêtre avec une étiquette blanche du sujet en haut à gauche.
- Barres accent qui montent une par une, posées sur le bas du cadre.
- Pas d'axe ni de chiffres, sauf si la voix les dit.

## À fournir
Le sujet et le nombre de barres.

## Briques
Arrow, Button, Card, Heading, Pin, Tag.
