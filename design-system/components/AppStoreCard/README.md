# AppStoreCard

La fiche d'une app dans le store.

## Quand
Ton app, la publier, son classement.

## Règles
- Icône accent arrondie, nom en capitales, catégorie, note, bouton Obtenir.
- Le classement ou la note dont on parle en gras.

## À fournir
Nom, catégorie, note, classement.

## Briques
Button, Card, Heading, Icon, Stars.

## Origine
Créé pour abdoul.dev en suivant la logique des composants existants.
