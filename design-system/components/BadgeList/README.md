# BadgeList

Liste à badges : une ligne de plus par élément cité.

## Quand
La voix énumère des éléments d'une même famille.

## Règles
- Une ligne de plus par élément cité, sur son mot.
- Badge numéroté accent, texte en capitales.
- L'élément dont on parle passe en accent plein ; les autres restent blancs.
- 7 lignes au plus.

## À fournir
Les libellés, dans l'ordre.

## Briques
Arrow, Badge, Button, Card, Pin.
