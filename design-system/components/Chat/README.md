# Chat

Chat / message : les bulles arrivent une à une ; la tienne en couleur.

## Quand
Une prise de contact, un message, un commentaire.

## Règles
- Barre avec le nom du contact (« UN INCONNU »).
- Ta bulle en accent à droite, la réponse en blanc à gauche.
- Les bulles arrivent une à une, le texte tapé.

## À fournir
Les messages, dans l'ordre.

## Briques
Arrow, Bubble, Button, Card, Heading, Pin, WindowBar.
