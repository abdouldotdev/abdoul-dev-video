# Detour

Flèche de détournement : l'usage habituel est barré, le détour part vers toi.

## Quand
Détourner un usage, contourner un canal.

## Règles
- L'usage habituel : flèche noire barrée d'une croix rouge.
- Le détour : flèche accent coudée vers le bloc accent « VOTRE INTÉRÊT ».

## À fournir
Le point de départ, l'usage, la cible.

## Briques
Arrow, Button, Card, Heading, Icon, Pin.
