# LabelStack

Étiquette + pile de cartes : une étiquette pose la question, les cartes répondent.

## Quand
Une question ou une catégorie, puis ses réponses (bon / mauvais, avant / après).

## Règles
- Étiquette accent en pilule au-dessus, cartes blanches dessous.
- Une coche ou une croix à droite de chaque carte.
- Un mot clé d'une carte peut passer en accent.

## À fournir
L'étiquette, les cartes, le verdict de chacune.

## Briques
Arrow, Button, Card, Pin, Tag.
