# CodeEditor

Éditeur de code : le code se tape ligne à ligne ; la valeur clé en couleur.

## Quand
La voix parle de code, d'une balise, d'un réglage technique.

## Règles
- Nom du fichier dans la barre, police mono.
- Le code se tape ligne à ligne ; la valeur dont on parle en accent.
- 10 lignes au plus.

## À fournir
Le nom du fichier et le code.

## Briques
Arrow, Button, Card, Pin, WindowBar.
