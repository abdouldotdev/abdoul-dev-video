# YouBlock

Bloc « TOI » : le spectateur placé dans le schéma.

## Quand
Le spectateur placé dans un schéma ou un exemple.

## Règles
- Bloc blanc « TOI », ou accent quand il est le sujet de la phrase.
- Toujours au même endroit d'une scène à l'autre quand l'exemple continue.

## À fournir
Rien : le mot est fixe.

## Briques
Arrow, Button, Card, Heading, Pin.
