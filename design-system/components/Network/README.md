# Network

TOI au centre d'un réseau de partenaires.

## Quand
Réseau, partenariats, communauté.

## Règles
- TOI en accent au centre, partenaires en tuiles autour, liens ink.
- Les liens apparaissent après les tuiles, sur le mot « s'entraident ».

## À fournir
Le nombre de partenaires et leurs labels.

## Briques
Card, Heading, Icon.

## Origine
Créé pour abdoul.dev en suivant la logique des composants existants.
