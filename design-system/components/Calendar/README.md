# Calendar

Un mois, une date précise, une régularité.

## Quand
Une date, une échéance, une habitude (« chaque lundi »).

## Règles
- Le mois réel en titre ; le jour dont on parle en accent.
- Une régularité : plusieurs jours en accent-tint.

## À fournir
Le mois et le ou les jours.

## Briques
Card, Heading, WindowBar.

## Origine
Créé pour abdoul.dev en suivant la logique des composants existants.
