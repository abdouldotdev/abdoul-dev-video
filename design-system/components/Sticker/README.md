# Sticker

Avatar (sticker) : une pose par émotion, ancrée en bas, coupée par le bord.

## Quand
Une émotion, un verdict, une adresse directe, une anecdote, l'appel à l'action.

## Règles
- Les poses Avatar ont déjà leur liseré : classe `sticker edged` (ombre seule). Objet détouré sans liseré : `sticker` (liseré blanc + ombre).
- Ancré en bas, coupé par le bord ; jamais avec un schéma.
- Quand l'afficher, combien de temps, quelle pose : règles vidéo (skill `abdoul-dev-video`).
- Pose absente : génération IA depuis l'image de référence, puis ajout au groupe Avatar.

## À fournir
La pose (clé du fichier, groupe Avatar).
- Gestes : point, explain, count, present, thumbs_up, thumbs_down, arms_crossed, facepalm, shrug, think, idea, arms_up, stop, whisper, wave, hands_heart, money, empty_pockets, stopwatch, laptop, phone, chart_up.
- Réactions, tête seule : shocked, angry, laugh, sad, star_eyes, heart_eyes, skeptical, mind_blown.
- Compter : count_1 à count_10.

## Briques
Arrow, Button, Heading, Pin, Sticker.
