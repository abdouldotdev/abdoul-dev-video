# MapPins

Plan + épingles : le principe : va où est ta cible ; TOI se rapproche.

## Quand
Le principe « va où se trouve ta cible ».

## Règles
- Plan de rues simple ; épingle blanche + étiquette pour la cible.
- L'épingle accent « TOI » apparaît puis se rapproche.
- C'est le visuel motif : il revient au début, au milieu et à la fin.

## À fournir
Les étiquettes (ta cible, ton client).

## Briques
Arrow, Button, Card, Heading, Icon, Pin, Tag.
