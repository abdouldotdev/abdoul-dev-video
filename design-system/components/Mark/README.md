# Mark

Les signes de verdict : coche verte, croix rouge, barré.

## Règles
- Coche et croix : à droite d'une carte ou seules, grandes.
- .strike barre un mot ou une ligne écartée, en rouge.
- yes et no ne servent qu'aux signes et aux chiffres, jamais en fond.
