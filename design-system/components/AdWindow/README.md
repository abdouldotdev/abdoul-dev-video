# AdWindow

Fenêtre pub : l'audience d'un créateur, « VOTRE PUB », clic sur payer.

## Quand
Payer pour apparaître devant une audience.

## Règles
- Barre « CRÉATEUR » + nombre d'abonnés, étiquette « Votre cible ».
- Bloc accent « VOTRE PUB », lignes simulées, bouton « Payer » cliqué par le curseur.

## À fournir
Le support (créateur, newsletter) et sa taille.

## Briques
Arrow, Button, Card, Heading, Icon, Pin, Tag, TextLine, WindowBar.
