# CalcCards

Cartes de calcul : le calcul se pose sous les yeux : + / − / =.

## Quand
Un calcul simple : chiffre d'affaires, charges, bénéfice.

## Règles
- Une carte par ligne, son libellé en haut à gauche, le montant à droite.
- Plus en vert, moins en rouge ; la carte du résultat en accent.
- Les cartes arrivent dans l'ordre du calcul.

## À fournir
Les libellés et montants.

## Briques
Arrow, Button, Card, Pin.
