# Keyboard

Un clavier : taper, une lettre, un raccourci.

## Quand
Taper, écrire, une touche, un mot.

## Règles
- AZERTY ; la ou les touches dont on parle en accent, une par mot.

## À fournir
Les touches à allumer.

## Briques
