# FlowStack

Une hiérarchie qui découle : principe → méthodes → techniques.

## Quand
Un concept qui en engendre d'autres, une pyramide d'idées.

## Règles
- 3 cartes empilées reliées par des flèches courtes vers le bas.
- Les petites cases matérialisent la quantité à chaque niveau.
- Un niveau rappelé passe en .bx.on.

## À fournir
Les niveaux et leur quantité.

## Briques
Arrow, Card.

## Origine
Créé pour abdoul.dev en suivant la logique des composants existants.
