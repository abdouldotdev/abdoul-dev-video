# StepsChecklist

Sommaire qui se coche : revient entre les parties ; ce qui est fait est coché.

## Quand
Le plan de la vidéo, au début puis entre deux parties.

## Règles
- Étiquette blanche « LES ÉTAPES » au-dessus.
- Les étapes faites portent une coche ; l'étape en cours passe en accent.
- Revient 3 ou 4 fois par vidéo, identique à l'exception de son état.

## À fournir
Les étapes et l'étape en cours.

## Briques
Arrow, Badge, Button, Card, Pin, Tag.
