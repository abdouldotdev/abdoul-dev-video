# SearchBar

Barre de recherche : le mot-clé se tape, l'autocomplétion apparaît.

## Quand
Ce que les gens tapent : mots-clés, autocomplétion.

## Règles
- Le texte se tape lettre par lettre (≈ 25 caractères par seconde) avec le curseur.
- Les suggestions arrivent une par une, la partie complétée en accent.
- Une loupe sur chaque suggestion.

## À fournir
Le début tapé et les suggestions.

## Briques
Arrow, Button, Card, Heading, Icon, Input, Pin.
