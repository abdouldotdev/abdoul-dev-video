# Slots

Grille de cases : le nombre annoncé devient N cases.

## Quand
Un nombre est annoncé (« il y a 7 méthodes »).

## Règles
- N cases numérotées, 4 par rangée au plus.
- Le titre « 7 MÉTHODES » au-dessus, le chiffre en accent.
- À chaque chapitre, la case en cours passe en accent ; plus tard, sert de barre de progression.

## À fournir
N et la case en cours.

## Briques
Arrow, Button, Card, Heading, Pin.
