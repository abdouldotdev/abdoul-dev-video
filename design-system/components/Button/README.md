# Button

Le bouton d'interface : Payer, Suivre, Obtenir, Valider.

## Règles
- Pilule, capitales, ombre courte shadow-small.
- Le curseur arrive sur le bouton au mot de l'action (« payer », « s'abonner ») : sa pointe se pose sur le bord bas droit, sans cacher le texte.
- Le bouton change d'état (Suivre → ✓ Suivi) au lieu de disparaître.

## Utilisée par
Voir la ligne « Briques » de chaque composant.
