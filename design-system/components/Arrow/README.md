# Arrow

La flèche qui relie deux blocs : cause, transfert, détour.

## Règles
- Trait de 3,5, pointe pleine de 13 de long.
- Part et arrive sur un bord, dans l'espace entre les blocs, jamais à travers.
- La pointe suit toujours la direction du dernier segment (une flèche coudée qui finit à l'horizontale a une pointe horizontale).
- Le trait s'arrête à la base de la pointe, qui touche presque le bloc : 8 unités d'écart.
- Angles droits uniquement pour les flèches coudées, jamais de diagonale entre deux blocs alignés.
- Elle se dessine du départ vers l'arrivée en 0,3 s.

## Utilisée par
Voir la ligne « Briques » de chaque composant.
