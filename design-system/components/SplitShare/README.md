# SplitShare

Une répartition entre deux personnes : parts, bénéfices.

## Quand
Associés, parts, partage d'un montant.

## Règles
- TOI en accent à gauche, l'autre à droite.
- Le chiffre sous chacun change avec la voix (500 → 50 % → 3 750 €).

## À fournir
Les deux rôles et les valeurs.

## Briques
Card, Heading, Icon, Tag.

## Origine
Créé pour abdoul.dev en suivant la logique des composants existants.
