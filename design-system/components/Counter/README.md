# Counter

Compteur d'abonnés : le chiffre défile, le bouton passe à « Suivi ».

## Quand
Une audience, des abonnés, une communauté.

## Règles
- Icône personne en accent, le nombre en grand accent, « ABONNÉS » dessous.
- Le nombre défile ; le bouton passe de « Suivre » à « ✓ Suivi » avec le curseur.

## À fournir
Le nom de l'audience, le nombre.

## Briques
Arrow, Button, Card, Heading, Icon, Pin, Tag, WindowBar.
