# FeaturePriority

Une liste longue réduite à l'essentiel.

## Quand
Prioriser, garder l'essentiel, couper le reste.

## Règles
- Les éléments gardés : badge accent et ligne ink.
- Les autres : badge blanc et ligne barrée en rouge, au mot « seulement ».

## À fournir
Le nombre total et le nombre gardé.

## Briques
Badge, Card, Heading, Mark, Tag, TextLine, WindowBar.

## Origine
Créé pour abdoul.dev en suivant la logique des composants existants.
