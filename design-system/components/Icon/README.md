# Icon

Le jeu d'icônes : trait noir, une seule forme accent.

## Règles
- Trait ink de 7 sur 100, bouts ronds ; une seule forme remplie en accent.
- Icône absente : Flat Icons « line », recolorée ; sinon dessinée dans ce style.
- Les billets et l'ampoule gardent leur couleur réelle (vert, jaune).

## Utilisée par
Voir la ligne « Briques » de chaque composant.
