# WindowBar

La barre de titre qui transforme une carte en fenêtre d'application.

## Règles
- Hauteur 30, séparée par un trait de 2,5.
- Le titre dit ce qu'on regarde (URL réaliste, nom du contact, du fichier).
- Un compteur ou un tag peut s'aligner à droite.

## Utilisée par
Voir la ligne « Briques » de chaque composant.
