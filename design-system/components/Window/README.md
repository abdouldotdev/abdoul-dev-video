# Window

Fenêtre de navigateur : fausse URL, le nom du produit et LE détail qui prouve.

## Quand
Montrer une vraie page : ton produit, un article, un site.

## Règles
- Barre avec 3 points et une fausse URL réaliste.
- Le nom du produit, une ligne en capitales avec 1 mot accent, 2 lignes simulées.
- LE détail qui prouve en étiquette accent (« ✓ problème résolu »).

## À fournir
L'URL, le nom, la phrase, le détail.

## Briques
Arrow, Button, Card, Heading, Pin, Tag, TextLine, WindowBar.
