# Tile

Tuile icône + label : un objet simple, une marque ou une catégorie, le mot dans la tuile.

## Quand
Un objet simple, un canal, une catégorie, une marque.

## Règles
- Icône au trait noir avec une seule forme accent, le label à l'intérieur de la tuile.
- Grille de 2 colonnes ; une tuile de plus par élément cité.
- Icône absente : Flat Icons recolorée, ou génération IA dans ce style.

## Marques
- Une marque citée se montre avec son vrai logo (brique LogoSlot), jamais avec une icône.

## À fournir
L'icône et le label.

## Briques
Arrow, Button, Card, Heading, Icon, Pin.
