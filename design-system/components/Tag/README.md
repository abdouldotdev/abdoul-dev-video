# Tag

L'étiquette en pilule : une question, un état, un nom posé sur un objet.

## Règles
- Toujours en capitales, 1 à 3 mots.
- Accent : la question ou l'élément actif. Blanc : un complément. Encre : un sens neutre (unité, catégorie).
- Dans une fenêtre ou un plan : sans ombre, 10 à 12.

## Utilisée par
Voir la ligne « Briques » de chaque composant.
