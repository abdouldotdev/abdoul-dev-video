# PhoneScreen

Un smartphone : l'app, l'écran d'accueil, ce que la cible voit.

## Quand
Une app, un écran mobile, « sur ton téléphone ».

## Règles
- Corps ink, écran tile, coins radius-card.
- L'app dont on parle en accent parmi les autres.
- Peut contenir une Notification ou un AppStoreCard réduit.

## À fournir
Le contenu de l'écran.

## Briques
Heading.

## Origine
Créé pour abdoul.dev en suivant la logique des composants existants.
