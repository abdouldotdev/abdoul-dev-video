# ReviewCard

Des avis clients avec leur note.

## Quand
Avis, témoignages, retours clients, avis 1 étoile.

## Règles
- Avatar rond, prénom, étoiles, une phrase réelle entre guillemets.
- Un avis négatif peut porter une croix ; un avis cité passe en .bx.on.

## À fournir
Les prénoms, notes et phrases.

## Briques
Card, Heading, Icon, Stars.

## Origine
Créé pour abdoul.dev en suivant la logique des composants existants.
