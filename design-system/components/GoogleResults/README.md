# GoogleResults

Résultats Google : « TON SITE » surligné ; le rang et la page évoluent avec la voix.

## Quand
Référencement, classement, « être trouvé ».

## Règles
- Vraie requête dans la barre (« plombier paris 14 »).
- « TON SITE » en accent avec son URL au-dessus ; les autres résultats en lignes simulées.
- Le rang et le pied « PAGE » évoluent avec la voix, dans la même scène.

## À fournir
La requête, le rang, la page.

## Briques
Arrow, Badge, Button, Card, Heading, Icon, Input, Pin, TextLine.
