# BusinessCard

La fiche d'établissement (Google Business) : nom, note, mots-clés.

## Quand
Référencement local, Google Maps, « ta fiche ».

## Règles
- Nom en capitales, note en étoiles, mots-clés en tags.
- Les mots-clés retenus en accent, les autres en blanc ; un mot écarté est barré.

## À fournir
Le nom, la note, les mots-clés.

## Briques
Card, Heading, Icon, Stars, Tag, WindowBar.

## Origine
Créé pour abdoul.dev en suivant la logique des composants existants.
