# Card

Le bloc de base : fond tile, contour noir, coins arrondis, ombre dure.

## Règles
- .bx : carte blanche ; .bx.on : carte accent (texte on-accent).
- Largeurs standard : 300 (pleine), 144 (2 colonnes, écart 12), 92 (3 colonnes), tuile carrée 100 à 140.
- Toujours le contour border-frame et l'ombre shadow-hard ; jamais d'ombre floue.
- Un seul .bx.on par scène, sauf la ligne en cours d'une liste.

## Utilisée par
Voir la ligne « Briques » de chaque composant.
