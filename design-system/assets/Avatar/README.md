# Avatar

Les 40 poses de l'avatar abdoul.dev, en WebP transparent. Le nom du fichier est la clé de la pose. Les images portent leur détourage : bande blanche épaisse (16 px pour ~900 px de haut) + trait encre (5 px) ; la coupe du bas n'est pas détourée (la pose est ancrée en bas). Sticker (`sticker edged`) ajoute seulement l'ombre. Une nouvelle pose reçoit le même détourage avant d'être ajoutée.

## Gestes (buste)
point, explain, count, present, thumbs_up, thumbs_down, arms_crossed, facepalm, shrug, think, idea, arms_up, stop, whisper, wave, hands_heart, money, empty_pockets, stopwatch, laptop, phone, chart_up. empty_pockets est en pied.

## Réactions (tête seule)
shocked, angry, laugh, sad, star_eyes, heart_eyes, skeptical, mind_blown.

## Compter
count_1 à count_10 : le nombre de doigts levés suit le numéro dit par la voix.

## Pose manquante
Génération IA depuis l'image de référence, détourage, nouvelle clé en anglais minuscule, ajout ici.
